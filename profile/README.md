# padid

**We build what is necessary.**

We are a small team of people who write software. We like things that are simple, clear, and useful, and we try to leave out everything else.

## How we think

- **Start with the need.** If a problem is not real, we do not build a solution for it.
- **Keep it small.** Less code means fewer bugs and a system that is easy to understand.
- **Understand what we ship.** Every part of our software should be something we can explain.
- **Improve step by step.** We ship something small, learn from it, and make it better.

## What we do

We design, build, and maintain software products. Our work lives in the repositories of this organization, and new ones will appear here as we grow.
